# Student Management System – Excel Dashboard

An interactive **Student Management System dashboard built using Microsoft Excel** to analyze and visualize student, faculty, course, fee, scholarship, placement, and demographic data.

### Key Features

* 📊 Interactive dashboard with **KPI cards** for total students, courses, faculty, revenue, course fees, and pending amounts.
* 🎯 **Slicers** for Gender, Age Group, City, Department, Company, Status, and Year.
* 📈 Visualized **student year distribution, gender composition, age profile, and student reach across cities**.
* 🏫 Analyzed **department-wise GPA and faculty strength**.
* 💰 Tracked **scholarship distribution and fee-related insights**.
* 💼 Presented **company-wise placement overview** for Infosys, TCS, and Wipro.
* 🔎 Designed an interactive dashboard to help users quickly filter and analyze student-related information.

### Tools & Skills

**Microsoft Excel | Pivot Tables | Pivot Charts | Slicers | Data Analysis | Data Visualization | Dashboard Development**
